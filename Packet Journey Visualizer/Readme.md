## 📌 About The Project

This project visualizes the path a packet of data takes when you send information over the internet.

Instead of treating networking as abstract theory, it shows:

- Your device
- Your local network / router
- Your ISP
- Intermediate routers on the internet
- The final destination server

At each stage it highlights **what information is visible** and **what is hidden**.

---

## 🎯 Learning Goals

- Understand how data actually moves across networks
- Learn the difference between local and public IP addresses
- See what metadata is exposed at different points
- Build a clear mental model of the internet’s structure

---

## ✨ Features

- Animated packet traveling across network stages
- Labels showing what each hop can see
- Simple controls to replay or pause the journey
- Clear explanations at every step
