## 📌 About The Project

This project is a minimal chat system with two parts:

- A **server** that listens for connections
- A **client** that connects and sends messages

The goal is not to build a polished chat app, but to see and understand the raw communication happening between two programs.

---

## 🎯 Learning Goals

- Understand sockets and ports
- See how TCP connections are established
- Observe how data is sent and received
- Learn the difference between client and server roles

---

## ✨ Features

- Basic text messaging between client and server
- Clear console logging of connection events
- Simple message sending and receiving
- Easy to inspect and modify

---

## 🛠️ Tech Stack

| Part     | Suggested Technology |
|----------|----------------------|
| Language | Python or Java       |

---

## 🗓 Development Phases

1. Create a basic server that accepts one connection
2. Create a client that connects and sends a message
3. Add two-way communication
4. Add logging so you can see every step
5. (Optional) Later add encryption and compare
