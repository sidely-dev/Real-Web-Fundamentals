## 📌 About The Project

This project runs two simple local servers:

- One using plain **HTTP**
- One using **HTTPS**

It then shows what an observer on the same network can and cannot see in each case.

---

## 🎯 Learning Goals

- Understand the difference between HTTP and HTTPS
- See what encryption actually protects
- Learn what still remains visible (metadata)
- Build intuition for why HTTPS matters

---

## ✨ Features

- Two local demo servers
- Clear comparison of visible data
- Simple explanations of what is protected
