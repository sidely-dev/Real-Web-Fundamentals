## 📌 About The Project

This tool scans your own computer for open ports and explains what common services usually run on them.  

It is built strictly for **learning and self-awareness**, not for scanning other machines.

---

## 🎯 Learning Goals

- Understand what ports are
- Learn common port numbers and their services
- See what is running on your own machine
- Develop better awareness of attack surface

---

## ✨ Features

- Scan localhost ports
- Display open ports
- Show common service names
- Simple and readable output
