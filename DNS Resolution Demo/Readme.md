## 📌 About The Project

When you visit a website, your computer must first translate the human-readable name (like `example.com`) into an IP address. This project makes that process visible.

---

## 🎯 Learning Goals

- Understand what DNS is and why it exists
- See the step-by-step lookup process
- Learn what information is revealed during a DNS query
- Understand the role of different DNS servers

---

## ✨ Features

- Enter a domain name
- Show the resolution steps
- Display the final IP address
- Simple explanations at each stage

## 🗓 Development Phases
